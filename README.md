# Vocational Lab Methodology

## About this project

This repository documents an ongoing initiative focused on transforming authentic industry scenarios into accessible hands-on learning environments for vocational education.

The project explores practical approaches for designing laboratory activities that preserve relevant workplace practices while considering common constraints in vocational education, including equipment cost, infrastructure, maintenance, available resources, and technological change.

Rather than proposing new technologies, the project focuses on how existing industry technologies and practices can be adapted into meaningful and accessible learning experiences.

## Project Objectives

- Identify challenges faced by vocational educators when developing authentic hands-on laboratory activities.
- Explore practical methods for translating industry scenarios into vocational learning environments.
- Investigate strategies for reducing implementation and maintenance costs while preserving relevant learning experiences.
- Document replicable laboratory designs, configurations, diagrams, and teaching resources.
- Develop and document practical case studies based on implemented learning environments.

## Project Development

The project is currently under development.

Initial work includes:

- educator needs and challenges analysis;
- development of a practical transformation methodology;
- documentation of laboratory design decisions;
- development of case studies;
- evaluation and refinement of the proposed approach.

Technical case studies and supporting resources will be added progressively as the project develops.

## Repository Structure

This repository will progressively include:

- methodology documentation;
- research instruments;
- laboratory case studies;
- technical diagrams;
- configuration examples;
- implementation guides;
- supporting educational resources;
- related publications and presentations.
