# Water Reservoir Level Control Laboratory

This directory documents the third case study in the Vocational Laboratory Methodology project.

The laboratory integrates an industrial 4–20 mA water-level sensor, signal conditioning, an Allen-Bradley Micro820 PLC, ladder logic, relays, pumps, and a physical reservoir.

The case is significant because the implemented solution emerged from real engineering constraints: sensor/PLC signal incompatibility, limited physical measurement range, analog resolution, electrical noise, and actuator cycling.
